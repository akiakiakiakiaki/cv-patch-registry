# Contributing to CV Patch Registry

Thank you for your interest in contributing to CV Patch Registry.

Contributions are welcome, including bug fixes, documentation improvements,
feature proposals, and code contributions.

## Before contributing

For substantial changes or new features, please open an issue first so the
proposed change can be discussed before implementation.

Smaller fixes and documentation changes can generally be submitted directly
as a pull request.

## Contributor requirements

By submitting a contribution, you confirm that:

- you have the right to submit the contribution;
- the contribution is your own work or you have the necessary rights to use it;
- the contribution does not knowingly include code or other material whose
  license is incompatible with this project.

Contributions may be reviewed, modified, rejected, or incorporated into the
project at the discretion of the project maintainers.

For substantial contributions, the project may require a separate Contributor
License Agreement (CLA) before accepting the contribution.
